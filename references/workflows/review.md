# Review

Select a plan before recording evidence. A review can inspect changes without a plan, but cannot mark criteria passed without an identified contract.

Run applicable gates: minimalism (ponytail when available), impact and coverage (graph or repository search), project lint/typechecks/tests, and python "<PLUGIN>/scripts/size_audit.py" "<PROJECT>". Review is diagnostic; fixes require an implementation request.

For UI, load gateway and design-law; inspect theme tokens, light/dark, accessibility and motion. Include apple-design for gestures/springs. For auth, use auth-law and security-law checklists.

Report findings ranked by severity and distinguish passed, failed and unavailable checks. With authorization to record workflow evidence, update only criteria for the selected plan that these checks prove. In read-only review mode return proposed evidence without changing the store.
